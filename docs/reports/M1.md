# Milestone 1 report — data, noise generator, ground truth

**Numbers**
* MCA subset: 278,030 real companies (5 states, 88 MB, keyless, GODL-India); 6 benchmarks
  (Abt-Buy, Amazon-Google, DBLP-ACM, Walmart-Amazon, Company, WDC Products 80% cc).
* Synthetic: 4 sources × 3 levels, 669,893 records/level, 645,547 true pairs, clusters 1–9.
* Measured noise rates match configured rates to within 0.003 (all sources, all levels).
* Identifier shortcut (exact CIN/GSTIN): recall 0.71 / 0.29 / 0.08 (easy/medium/hard),
  precision 0.9999.
* Normaliser recovers the exact name key after Devanagari noise 78.6%, after romanisation
  variants 97.0%.
* Split 194,623 / 41,705 / 41,702 entities; all leakage checks pass; 467 tests;
  byte-identical regeneration; `make data` ≈ 1.5 min (+ ~80 s first-time ingest).

**Problems found and fixed**
* Random synthetic GSTINs collided across entities (10,406 false pairs) → bijective serial (25 left, from typos).
* Shared normaliser/generator vocabulary made noise self-undoing (Devanagari 99.4%) → held-out lexicon.
* City-parser fallback mis-read the last word as a city; ITRANS left ॉ untransliterated.
* WDC pair files carry `cluster_id_*` = the label → must be dropped in M2 loaders.

**Open issues**

* Devanagari rendering is heuristic; noise is independent per type; MCA snapshot is 2015.
